# Forensic-case-anomaly-detection-system
🔍 Forensic Case Anomaly Detection System
Project Overview

This project is a Data Science + Machine Learning based anomaly detection system designed to identify suspicious patterns in forensic case records.

It helps investigators detect:

Delays in FIR registration

Delays in Post-Mortem reports

Tampering indicators

Multiple suspicious modifications

Unusual narrative patterns

Hidden anomalies using Hybrid ML Models

The goal is to reduce investigation delays and support faster justice delivery.
